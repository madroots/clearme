# Store upload kit

Everything you need to paste into the Chrome Web Store Developer Dashboard.
Nothing here is part of the extension ZIP.

| Dashboard location | Use |
| --- | --- |
| Store listing → Name / Summary / Description | `listing.md` |
| Store listing → Category | Developer Tools |
| Store listing → Screenshots | `screenshots/01-clearme.jpg`, `screenshots/02-clearme.jpg` |
| Store listing → Icon | Upload `icons/icon128.png` |
| Privacy practices → Single purpose, permission justifications, remote code, data use | `privacy-practices.md` |
| Privacy practices → Privacy policy URL | `https://github.com/madroots/clearme/blob/main/PRIVACY.md` |
| Test instructions | `test-instructions.md` |
| Package → Upload | `dist/clearme-1.0.0.zip` |
| Distribution | Public |

Screenshots are 1280×800 JPEGs (converted from the supplied 1312×816 captures,
metadata stripped). Upload both.

Before submitting, give the screenshots a once-over for personal tabs,
bookmarks or account details — they will be public.
