# ClearMe Privacy Policy

**Effective date:** 2026-10-21

ClearMe is a browser extension that clears cookies, cache and site data for the
website you are on when you click its toolbar icon.

## What ClearMe handles

When you click the icon, ClearMe reads the current tab's URL so it can target
the correct site. It then asks the browser to delete the data types you have
selected in Options: cookies, HTTP cache, Cache Storage, localStorage,
sessionStorage, IndexedDB, service workers and File System data.

ClearMe does not read, inspect, retain or transmit cookie values, page content,
storage contents, browsing history or any other URLs. The clearing is performed
locally by the browser.

## Collection and sharing

ClearMe collects no user data, has no analytics, runs no remote servers and
shares nothing with third parties. There are no accounts and no tracking.

## Settings

Your clearing preferences (the checkboxes and the reload option) are stored
with `chrome.storage.sync`. If browser sync is enabled, those preferences are
stored in your browser's sync account and are governed by the sync provider's
privacy policy. ClearMe itself does not operate a server.

## Permissions

- `browsingData` — deletes the selected site data; no data is read or sent.
- `storage` — saves your preferences.
- `activeTab` — lets ClearMe read the current tab's URL after you click the
  icon, so it clears the right site. ClearMe injects no scripts and reads no
  page content.

## Limited Use

ClearMe's use of any browser data is limited to providing its single purpose:
clearing site data for the page you explicitly activate it on. ClearMe does not
sell or transfer user data, does not use it for advertising or profiling, and
does not allow humans to read it.
